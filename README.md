# RecamasSequence
A C++ implemetation for calculating Recamas Sequense that can either output directly to the terminal, or write to a file.

## How to use main.cpp
This implimiation can take two arguments when run, the first is which nuber in the sequence you want to calculate too, and the other (optional) argument is the name of the file (new or exsisting) you want it to write to instead of outputing to the terminal

## How to use findN.cpp
FindN.cpp have a implemetation to find which position in the sequene a number is locaded at
